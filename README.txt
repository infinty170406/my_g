MY G❣️ — Installation

1. Place le fichier audio du site actuel dans :
   assets/music.mp3

2. Ouvre index.html dans un navigateur.

3. La musique NE SE LANCE PAS AUTOMATIQUEMENT.
   Elle démarre uniquement lorsque l'utilisateur clique sur « Activer la musique ».

4. Pour publier : Vercel, Netlify ou GitHub Pages conviennent.
